**Windows 10/11 x64 · Experimental prerelease · Your music. Your drive. Your soundtrack.**

> Beta 1.7 builds on the tested Most Wanted audio engine and concentrates on long-playlist preparation, installer feedback and Windows reliability. This is an experimental public beta, **not a claim that every game version and feature was verified**.

## ⬇️ Download

After publication, use [GitHub Releases](https://github.com/ValentineBSAA/XNFS-Playlist-Builder-/releases) and download **`XNFS-Playlist-Builder-3.2-Beta-1.7-Public.zip`**. Extract it, then run **`XNFS-Playlist-Builder-3.2-Beta-1.7-Setup.exe`**. **Windows 10/11 x64**, a compatible legally obtained Most Wanted/Carbon game, local music, and an existing compatible ASI loader are required. The installer is unsigned; verify its origin and [SHA-256](docs/SHA256-OF-BETA-1.7.txt).

The Public ZIP ships the Windows Setup EXE, read-me files, change notes and third-party notices. It **does not** contain the editable builder code. GitHub's autogenerated Source code ZIP is not the Windows installer.

## ✨ New in Beta 1.7

- **Progress you can follow:** live per-song analysis / loudness-leveling progress, file counts, named installation stages and an ETA when timing data becomes available.
- **Cleaner finish:** choose **OK** on the installation completion review to return to the main workspace.
- **Windows identity:** embedded application icon with consistent taskbar and shortcut presentation.
- **Better custom pursuit installation:** eliminated redundant source-audio reads, retained verification of written files and shows restore / cleanup / game-player-install work after the last audio file.
- **Upgraded-app crash correction:** the handoff records reproducing a Shiboken DLL error after upgrading over an older runtime and a successful in-place repair after moving runtime dependencies into a versioned directory. This is evidence for that issue, **not a guarantee against every Windows crash**.
- **Larger real gameplay test:** developer-reported successful playback of **45 custom interactive Pursuit songs** (including one manually added track), **45 Safe House songs**, and **45 Free Roam songs**; installation progress completed for the custom pursuit test.

## 🎚️ Developer-verified engine audio

**Confirmed by developer valentine:** adjusting car engine sound volume is a **manual, in-game operation**. In **Most Wanted**, use **Audio options → Car Volume** to balance engine noise against the music. The builder's **Music** level controls music independently and does not automatically change engine volume. The **65% default music setting** is a useful starting point, not a mandatory listening balance. **This is a verified operating requirement, not a feature awaiting a test.**

## 🟡 Most Wanted

Safe House (also menus), Free Roam, Race, Pursuit and Shared pools remain available. Configurable fades and finish-current-song transitions are supported. Choose **one** pursuit mode: continuous ordinary Pursuit playlist, original adaptive score, or custom interactive library music.

Specific developer listening sessions confirmed Safe House fades, scripted prologue audio, Free Roam, ordinary pursuit handoff, custom interactive tracks, **T** skipping, **EA Trax** titles, the independent 65% mix and the original-score exit fade. The original adaptive score is **not T-skippable**.

**Important limits:** the revised custom-interactive exit fade, incoming fade at every natural custom track change and first song after switching saves have not received complete separate game acceptance. Modified `speed.exe` may pass all **61 music-hook signature** checks, but **actual PLAK gameplay remains unverified**. A car-body rendering issue seen on a heavily modified installation remains unattributed.

## 🔵 Carbon

Menu, Muscle, Tuner, Exotic and Shared playlists, optional/configurable **F9** skip and crew-speech ducking/balance settings remain available. Earlier **Carbon 1.2** gameplay confirmed class routing, F9 and ducking. Installer payloads exist for the inspected **1.2 and 1.4** executables, but 1.4 real gameplay is not fully verified.

Original Canyon/Pursuit scoring and Drift audio controls remain **experimental**. The runtime has **no independent custom Canyon/Pursuit song pools**. The intermittent **Load Complete** crash remains unresolved; its cause has not been established.

## 🛡️ Safety, troubleshooting and credits

Desktop Setup does **not** silently change game files. Using game-side **Install selected features**, **Build / Save**, or restore operations **can**. Close the game and copy your full game folder before installation. Original adaptive Most Wanted soundtrack extraction runs **inside Most Wanted** after its native install feature has been enabled.

Use **Support** to review and save a diagnostics ZIP with `diagnostics.txt` and `diagnostics.json`; nothing is uploaded automatically.
