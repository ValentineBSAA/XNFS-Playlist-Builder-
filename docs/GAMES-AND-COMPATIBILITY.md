# 🎮 Carbon vs. Most Wanted: features and compatibility

**Both games are supported by XNFS Playlist Builder.** They share the same music-library foundation but use different soundtracks inside the game. Not all in-game features are complete or fully verified in Beta 1.4.

## At a glance

| What matters | 🔵 Carbon (2006) | 🟡 Most Wanted (2005) |
| --- | --- | --- |
| Custom music | Yes | Yes |
| Four playlists | Menu, Muscle, Tuner, Exotic | Safe House, Free Roam, Race, Pursuit |
| Automatic playlist selection | **Car class** | **Driving situation**, with interactive Pursuit system unfinished |
| Skip a track | **F9**, optional | **T** while driving |
| Shuffle with repeat protection | Available | Available |
| Optional volume-leveled music copies | Available | Available |
| Automatic genre suggestions | Available | Available |
| Manual playlist editing | Available | Available |
| Game-specific special feature | Optional **crew-dialogue ducking** | **EA Trax notifications** |
| Interactive pursuit music | Not applicable | **Not fully implemented in public Beta 1.4; completion planned for Beta 1.5 (not release-ready)** |
| Backup and restoration tools | Available, with valid records | Available, with valid records |

**Safe House in Most Wanted also includes main-menu music.** There isn't a separate menu playlist to configure.

**The Pursuit playlist is available to edit, but the full interactive pursuit-music system was never implemented in Beta 1.4.** It is an incomplete feature, not a regression from previously working functionality. Completing the implementation is being addressed for **Beta 1.5**, which is **not ready for release**.

**Police-radio ducking for Most Wanted isn't included** in this release.

## What has actually been tested?

| Game/setup | Current evidence |
| --- | --- |
| **Carbon 1.2** | Developer in-game testing for soundtrack playback, car-class routing, skipping and leveled playback |
| **Carbon 1.4** | Version-matched player prepared and checked offline; new live gameplay testing still needed |
| **Most Wanted 2005** | Earlier playback behavior, T-key skipping and restoration tested by the developer; **full interactive pursuit music was not implemented**; newest combined menu/Safe House behavior still needs a new live test |

These are **limited developer tests**, not a guarantee that all PCs or modified game setups will work. The project is maintained by a single developer, who cannot test every feature and combination alone. Confirm your game's exact executable version before applying features.

## Before changing files

- Use **Windows 10 or 11, 64-bit**.
- Bring your own game installations and music; neither is included.
- Have a **compatible ASI loader** for in-game integration.
- Read warnings from the installer; do not force an unsupported executable.
- Back up your game folder and any existing XNFSMusicPlayer setup.
- Close the game before installing features, building playlists or restoring files.
